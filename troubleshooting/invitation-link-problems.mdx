---
title: "Invitation Link Problems"
description: "Fix common issues when opening or completing a Clientza owner invitation link."
---

If your invitation link does not work, check these items in order.

## Step 1: Use the latest invitation email

If you received multiple emails, open the newest one first.

## Step 2: Confirm the invited email account

Make sure you are using the same email address that was invited.

## Step 3: Try again in a private window

Open the invitation link in a private/incognito browser window to avoid stale session conflicts.

## Step 4: Check if you already have an account

If the invitation flow offers an existing-account path, follow that option and sign in.

## Step 5: Capture the exact error message

If the issue continues, note the on-screen message and share it with your support contact.
