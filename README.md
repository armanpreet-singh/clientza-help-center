# Clientza Help Center

Welcome to the Clientza Help Center documentation repository.

This repository contains the customer-facing documentation for **Clientza**, helping business owners understand the platform, set up their accounts, manage their business, and troubleshoot common issues.

## Documentation Goals

- Help new owners get started with Clientza.
- Explain how to use the Owner dashboard.
- Provide step-by-step guides for supported features.
- Answer frequently asked questions.
- Help owners resolve common problems.
- Keep documentation accurate as Clientza evolves.

## Documentation Platform

The Help Center is built and maintained using [Mintlify](https://mintlify.com/).

## Documentation Principles

- Document verified product functionality.
- Use clear, practical, step-by-step instructions.
- Avoid presenting unfinished features as available.
- Keep business policies and requirements accurate.
- Review documentation whenever the product changes.

## Project Status

The Help Center is currently under development. Articles, navigation, branding, and publishing configuration will be added and reviewed before the first public release.
